«Мой пропуск» — Android-приложение для просмотра выданного электронного пропуска. Оно показывает данные владельца, срок действия, статус и QR-код пропуска.

Приложение написано на Kotlin с использованием Jetpack Compose и Material 3. Задания и правила сдачи приведены в [TASK.md](TASK.md).

## Требования

- Android Studio с JDK 17 или новее.
- Android SDK 36.
- Эмулятор или устройство с Android 8.0 (API 26) или новее.

Версии Gradle и зависимостей зафиксированы в проекте. При первой сборке требуется доступ к сети для их загрузки.

## Запуск

1. Откройте корневой каталог проекта в Android Studio и дождитесь синхронизации Gradle.
2. Создайте и запустите эмулятор или подключите устройство.
3. Выберите конфигурацию `app` и нажмите **Run**.

Для сборки APK из корня проекта выполните:

```bash
./gradlew assembleDebug
```

APK будет создан по пути `app/build/outputs/apk/debug/app-debug.apk`.

Приложение использует демонстрационный источник данных: каждый третий запрос завершается ошибкой. Это позволяет проверить поведение при отсутствии связи.
